01

Asymptotic Behavior and Self-Similar Profiles of the Heat Equation in RN

This thesis studies the long-time behavior of solutions to the classical heat equation in RN. A central result establishes that solutions converge toward a self-similar Gaussian profile as t → ∞ — drawing a striking parallel with the Central Limit Theorem in probability theory.

Convergence rates of order t−1/2 in L1 and t−1 in higher norms are derived using Fourier analysis and interpolation inequalities. The work rigorously connects PDE asymptotic theory with probabilistic intuition, contributing a formal framework for understanding the "averaging effect" of diffusion operators.

02

Tax Fraud Detection Using Classification in R

This project develops a machine learning pipeline to detect potentially fraudulent tax declarations from structured financial and non-financial company data. The work involves feature engineering, class imbalance handling, and comparative evaluation of supervised learning models.

Classification algorithms including decision trees, logistic regression, and ensemble methods were trained and validated on labeled fiscal datasets. The resulting model identifies suspicious patterns in tax submissions with measurable precision and recall, demonstrating the applicability of ML to financial compliance and fraud prevention.

Graph Theory & Scheduling

This project applies combinatorial mathematics to model and solve concrete planning and scheduling problems. Using graph-theoretic frameworks, the work maps resource allocation and sequencing challenges onto graph structures, enabling the application of known algorithmic solutions from discrete mathematics.

06

Portfolio Optimization Dashboard

This project is a fully interactive financial dashboard built with Streamlit, applying Modern Portfolio Theory (MPT) to optimize stock portfolio allocation using real market data fetched from Yahoo Finance. The core objective is to find the asset weights that maximize the Sharpe Ratio — the canonical measure of risk-adjusted return — defined as:

Sharpe Ratio = (Expected Return − Risk-Free Rate) / Portfolio Volatility

The dashboard runs a Monte Carlo simulation over thousands of random portfolio weight combinations, computing expected return, volatility (via the covariance matrix of asset returns), and Sharpe Ratio for each. The efficient frontier is then visualized, and the optimal allocation — the portfolio sitting at the frontier's peak — is highlighted and returned to the user.

Key features include live stock data retrieval, interactive asset selection, full covariance-based risk decomposition, and allocation visualization charts — making sophisticated quantitative finance accessible through a clean, user-friendly interface.
